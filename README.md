# Ethereum Contribution Model

A Bradley-Terry model for weighting Ethereum repository contributions based on pairwise juror comparisons.

##  Key Insight

**Bradley-Terry (100%) + Machine Learning (0%)**

After extensive testing, we discovered that pure Bradley-Terry model outperforms machine learning approaches for pairwise comparison data.

- Bradley-Terry correlation with targets: 0.654
- Best feature correlation with targets: 0.248  
- ML on residuals: -0.455 (anti-predictive)
